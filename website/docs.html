Quick Start — New IPLoop Platform

Step 1: Create an account or sign in at platform.iploop.io.

Step 2: Save your API key, proxy username and proxy password privately. The dashboard password, proxy password and API key are different credentials.

Step 3: Add bandwidth, then copy the HTTP and SOCKS5 endpoints from the dashboard’s Connect section. Set the values below to your own credentials and endpoints before running the examples.

PROXY_USERNAME='YOUR_PROXY_USERNAME'
PROXY_PASSWORD='YOUR_PROXY_PASSWORD'
HTTP_PROXY_ENDPOINT='COPY_HTTP_ENDPOINT_FROM_CONNECT'
SOCKS5_PROXY_ENDPOINT='COPY_SOCKS5_ENDPOINT_FROM_CONNECT'

curl --proxy "$HTTP_PROXY_ENDPOINT" \
  --proxy-user "${PROXY_USERNAME}-country-us:${PROXY_PASSWORD}" \
  "https://api.ipify.org?format=json"

Authentication

Proxy traffic: use your proxy username and proxy password. Country and session options belong in the username, not the API key or proxy password.

Dashboard: use your email and dashboard password, or choose API-key login. Keep your key private; never paste real credentials into public examples.

These instructions apply to new accounts on platform.iploop.io. Existing legacy integrations use a different key-only format and are not silently migrated by changing a URL.

HTTP and SOCKS5

Use the current endpoints shown in Connect. An HTTPS target protects the target connection; it does not by itself establish encrypted authentication to the proxy.

# HTTP CONNECT to an HTTPS target
curl --proxy "$HTTP_PROXY_ENDPOINT" \
  --proxy-user "${PROXY_USERNAME}-country-us:${PROXY_PASSWORD}" \
  "https://example.com"

# SOCKS5 with target DNS resolved through the proxy
curl --socks5-hostname "$SOCKS5_PROXY_ENDPOINT" \
  --proxy-user "${PROXY_USERNAME}-country-us:${PROXY_PASSWORD}" \
  "https://api.ipify.org?format=json"

Successful connection does not guarantee that a target website will accept a request. Inspect its returned status and content.

Country Targeting

Append an ISO alpha-2 country code to your proxy username. For example: -country-us, -country-ca, -country-gb, -country-de, -country-au or -country-tr. Availability depends on the live pool.

curl --proxy "$HTTP_PROXY_ENDPOINT" \
  --proxy-user "${PROXY_USERNAME}-country-gb:${PROXY_PASSWORD}" \
  "https://ipinfo.io/json"

Current limitation: state/city selectors are not accepted in the current verified new-platform path. Do not rely on state, city, ZIP or ASN restrictions until explicitly verified for your integration. Invalid country selectors must not be used: the backend may return an unintended geography. The V2 Python SDK validates country codes locally.

Rotation and Sticky Sessions

Omit a session ID for ordinary rotating selection. Connections and pooled clients may reuse an exit; rotation does not guarantee a unique, never-used IP on every request.

# Reuse this ID for requests belonging to the same sticky session
curl --proxy "$HTTP_PROXY_ENDPOINT" \
  --proxy-user "${PROXY_USERNAME}-country-us-session-demo123:${PROXY_PASSWORD}" \
  "https://api.ipify.org?format=json"

# Request a five-minute session (duration is in minutes)
curl --proxy "$HTTP_PROXY_ENDPOINT" \
  --proxy-user "${PROXY_USERNAME}-country-us-session-demo123-sesstime-5:${PROXY_PASSWORD}" \
  "https://api.ipify.org?format=json"

Use letters, digits or underscores in SDK session IDs. Change the ID to request a different session. Device availability can cause an exit change; no uninterrupted fixed-IP lifetime is guaranteed.

Python SDK — V2 Support

Use iploop-sdk 1.8.2 or newer with all three account credentials. Key-only construction retains legacy mode; it is not the new-platform example.

python -m pip install 'iploop-sdk[async,socks]>=1.8.2'
import os
from iploop import IPLoop

client = IPLoop(
    api_key=os.environ['IPLOOP_API_KEY'],
    proxy_username=os.environ['IPLOOP_PROXY_USERNAME'],
    proxy_password=os.environ['IPLOOP_PROXY_PASSWORD'],
)
r = client.get('https://example.com', country='US', retries=2, timeout=15)
r.raise_for_status()
print(r.text)

session = client.session(session_id='my_session1', country='US', lifetime=5)
r = session.get('https://api.ipify.org?format=json', retries=1)

usage = client.usage()
print(usage['account']['balance_gb'])  # decimal GB
print(usage['daily'])                # daily byte counts

Set those environment variables to your own API key, proxy username and proxy password first. For synchronous SOCKS5, pass proxy_protocol='socks5h'. Async HTTP is supported through AsyncIPLoop with the same credentials and an async context manager; async SOCKS is explicitly unsupported.

V2 city targeting, rendering and country-inventory/support-message helpers are not claimed as supported by this release. They raise explicit unsupported-feature errors rather than silently calling legacy services. Extractor and anti-bot results remain target-dependent.

Errors and Usage

401 — Account API authentication was rejected.
407 — Proxy authentication was rejected; verify the proxy credentials and syntax.
429 — Back off and respect the service response.
502 / 503 — Temporary connection/service failure; use bounded retries.

SOCKS authentication failures may appear as client connection errors instead of an HTTP code. Do not retry invalid credentials indefinitely.

The dashboard displays balance in decimal GB. The underlying account balance is bytes; usage rows also report bytes. Owner credits are separate from paid purchases. Request/success counters are service metrics, not a guarantee of successful target-site business results.

Request history is available for requests captured while account logging is enabled. Enable logging in the dashboard before a bounded diagnostic run, and turn it off when finished. An empty history view does not prove zero traffic when logging was disabled; balance and daily usage are separate views.
