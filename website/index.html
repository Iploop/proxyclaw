Quick Start

Install and start fetching in under 30 seconds.

1. Install (pick one)

# ClawHub V2 skill (latest: 3.0.3)
$ clawhub install proxyclaw
# Option B: Direct from GitHub
$ git clone https://github.com/Iploop/proxyclaw.git
# Option C: Python SDK (recommended)
$ pip install --upgrade iploop-sdk

Python SDK usage:

# V2 support requires iploop-sdk 1.8.3 or newer
$ pip install --upgrade iploop-sdk
# V2: separate account key and proxy credentials
import os
from iploop import IPLoop
client = IPLoop(
  api_key=os.environ["IPLOOP_API_KEY"],
  proxy_username=os.environ["IPLOOP_PROXY_USERNAME"],
  proxy_password=os.environ["IPLOOP_PROXY_PASSWORD"])
r = client.get("https://example.com", country="US")
r.raise_for_status()

Target acceptance varies. V2 HTTP, SOCKS5 and sticky examples are in the docs. GitHub →

2. Configure Your Credentials

# Get your credentials at platform.iploop.io
export IPLOOP_API_KEY="your-api-key"
export IPLOOP_PROXY_USERNAME="your-proxy-username"
export IPLOOP_PROXY_PASSWORD="your-proxy-password"
# Raw proxy / Python SDK: verified V2 guide.
# Browser API examples below are a separate integration;
# their token compatibility is not established by this proxy SDK setup.

3. Separate Browser Integration (not V2-certified)

# Fetch a page through residential proxy
curl -s -G \
  --data-urlencode "url=https://example.com" \
  -H "Authorization: Bearer YOUR_SEPARATE_BROWSER_API_TOKEN" \
  "https://api.proxyclaw.ai/browser"

4. Browser Geo Options (separate integration)

# Fetch from a specific country
curl -s -G \
  --data-urlencode "url=https://example.com" \
  --data-urlencode "country=US" \
  -H "Authorization: Bearer YOUR_SEPARATE_BROWSER_API_TOKEN" \
  "https://api.proxyclaw.ai/browser"
